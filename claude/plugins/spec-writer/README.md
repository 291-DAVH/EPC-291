# spec-writer

Technical specification (PG/ET) writer for any engineering discipline, backed by the Document Writer agent. Reference material lives in local/dev-knowledge, never in this repo.

- Version: 0.1.0 (workflow) - **needs-neutral-templates**
- Entitlement: `feature.specs`
- Python: stdlib only

- `doc-quality` ^0.1.0

- `.docx`: internal+deliverable
- `.pdf`: internal+deliverable

See `plugin.json` for the full manifest. Legacy origin: `00-Template-Claude/.claude/skills/generar-pliego`.

This plugin is packaging only. The code lives in `engine/documents` and is copied into the built plugin under `lib/` (set `PYTHONPATH="${CLAUDE_PLUGIN_ROOT}/lib"`).
