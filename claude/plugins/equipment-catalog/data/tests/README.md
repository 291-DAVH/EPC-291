# Tests — Plugin EQUIPMENT

Carpeta para probar este plugin de forma independiente, sin ejecutar el framework completo.

## Uso rápido
```bash
python run_test.py         # ejecuta todos los tests del plugin
```

## Convención
- `test_<nombre>.py`  → script de test
- `input/`            → archivos de entrada de prueba
- `../output/`        → resultados generados (SVG, PDF, PNG)
