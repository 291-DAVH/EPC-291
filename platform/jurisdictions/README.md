# jurisdictions

One folder per country (ISO 3166 alpha-2). Each standard becomes `<domain>/<STANDARD-ID>/rules.json` promoted from `dev-knowledge/standards/<CC>/<STANDARD-ID>/draft/` (schema: `schemas/rules.schema.json`). Currently the AEA tables still live inside `hub/aea-calc/scripts/` (`aea_tables.json`, `rules/`) and must be moved here once validated.
