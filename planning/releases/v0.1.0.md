# v0.1.0 (2026-10-23)

Stories delivered: US-0001 to US-0008, US-0010, US-0011, US-0013, US-0014, US-0015, US-0017 and US-0021 (SPRINT-00 and SPRINT-01).

## Highlights
- **Engine** (`engine/`): five Python packages (calc, rules, standards, drawing, documents) with their own tests; Argentina country pack structure.
- **Claude layer** (`claude/`): 12 plugins (packaging only), 14 skills, marketplace in Claude Code's official layout, validated with `claude plugin validate --strict`.
- **Backend** (`backend/`): FastAPI modular monolith with 12 modules, `public.py` facades and enforced boundaries (import-linter and architecture tests).
- **Frontend** (`frontend/`): customer web app and separate admin console over a shared `@epc/ui` package; project pages with Plan (Gantt, WBS), Deliverables, Input data, Requirements, Reports and, for the engineer role, Engineering (SVG diagrams and text lists).
- **Management**: WBS with progress roll-up, schedule with critical path, internal backlog; customer input pipeline to requirements.
- **Database and infra**: Alembic baseline, Docker, compose with PostgreSQL, CI workflow, test battery of 20 checks.
- **Policies**: plugins govern skills, `.svg` never delivered, copyrighted material kept out of git (`local/`).

## Known limits
- No authentication or organizations yet (roles come from environment variables); the application is file-based, the database is created but not read.
- Calculation tables and standards rules are pending validation against the official documents; no rules are promoted to production.
- Intake analysis is run manually; MLD generator is pending; only low-voltage electrical.
- Docker images and the CI workflow were validated statically (no Docker or GitHub run before this release).
- No license chosen yet (all rights reserved).
- Desktop edition (Rust) and FreeCAD/3D are deferred (ADR-0007, ADR-0008).
