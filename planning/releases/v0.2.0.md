# v0.2.0 (2026-10-23)

Stories delivered since v0.1.0: US-0014, US-0015, US-0017, US-0021 (and the retirement of `platform/`).

## Highlights
- **Management:** WBS with weighted progress, schedule with critical path, internal backlog; read-only Plan tab for the customer.
- **Engineering (engineer/admin role):** SVG diagram preview, text lists, editable design criteria with origin and history, and the SLD data form that runs the plugin generator unchanged (SVG, DXF, PDF and calculation per sheet).
- **Deliverables:** PDF next to DXF drawings and a ZIP delivery package with `INDICE.csv` and SHA-256 (named with the revision the client sees, `Rev00`).
- **Repository:** `platform/` retired; single `.claude/`; `database/`, `infra/`, CI workflow; README with logo; ADR-0007 (Rust desktop, deferred) and ADR-0008 (2D CAD with ezdxf and shapely).
- **Quality:** 21-check battery, now also run in a clean Linux container; Docker images built and the compose stack run; PostgreSQL migration round trip verified.

## Fixed (important)
The backend module `knowledge` was hidden by an ignore rule and missing from v0.1.0; a clean checkout could not import the backend. Fixed, with a gate check to prevent it.

## Known limits
- Design criteria and calculation tables are not validated against the standards; the SLD generator does not read the criteria yet.
- No publish step from Engineering to Deliverables (demo deliverables are simulated); no authentication or organizations; the application is file-based.
- GitHub Actions could not be read from here (private repository): the workflow was reproduced step by step in a clean Linux container instead.
- No license chosen (all rights reserved). Desktop (Rust) and FreeCAD/3D are deferred.
